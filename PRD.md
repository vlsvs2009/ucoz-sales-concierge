# AI Sales Concierge для uCoz — PRD (MVP, хакатон 4.09.2026)

Владелец: Владимир (PM) · Команда: Станислав, Андрей · Срок: демо вечером 4.09 · Статус: в работе

## 1. Проблема

Владелец сайта на uCoz (сервис, агентство, локальный бизнес, каталог) теряет посетителей на этапе pre-sale: человек не нашёл ответ на странице, не захотел заполнять форму «Обратная связь» и ушёл. Форма собирает 1–3% посетителей, остальные вопросы («сколько стоит», «есть ли в наличии», «работаете ли в субботу», «подойдёт ли мне») остаются без ответа. Чат-боты по сценариям дорого настраивать, а универсальные ChatGPT-виджеты галлюцинируют и обещают то, чего нет на сайте.

## 2. Решение в одной фразе

Виджет-консультант, который устанавливается на uCoz-сайт одной строкой, отвечает только по реальному контенту сайта, уточняет потребность посетителя и доводит разговор до контакта — а контакт с резюме диалога падает владельцу в кабинет.

## 3. Для кого

Основной сегмент: действующие владельцы uCoz-сайтов с услугами и ценами на страницах (автосервисы, клиники, ремонт, обучение, туризм, B2B-услуги) и небольшие каталоги/магазины. Вторичный: агентства и веб-мастера, которые обслуживают десятки сайтов и могут ставить консьержа как upsell.

Персона для демо: владелец автосервиса «Гараж №1» (наша предметная область по DualClutch) — есть страницы услуг, цены, часы работы, адрес, FAQ.

## 4. User stories (MVP)

Владелец сайта: вставляю URL сайта → через минуту получаю сниппет → вставляю в шаблон uCoz → на сайте появился консультант. В кабинете вижу лиды: имя, телефон/email, что человеку нужно, резюме диалога, «горячесть».

Посетитель: задаю вопрос своими словами → получаю ответ по сайту со ссылкой на страницу → консультант уточняет 1–2 детали → предлагает оставить контакт/записаться → я оставляю телефон и получаю подтверждение.

## 5. Scope MVP (что делаем сегодня)

Индексация одного сайта по URL (sitemap + обход ссылок, до 150 страниц), чистка HTML, разбивка на фрагменты, поиск BM25. Агент на Claude с системным промптом «отвечай только по контенту сайта, не выдумывай цен и обещаний, при неуверенности — предложи связаться с менеджером». Пять сценариев квалификации через конфиг сайта (цель визита, срочность, бюджет/масштаб, контакт). Tool `capture_lead`: структурированный лид + оценка hot/warm/cold + резюме. Виджет: чат-пузырь, ответы с источниками, быстрые кнопки, форма контакта, мобильная вёрстка. Админка: список сайтов, кнопка «Проиндексировать», список лидов и диалогов, сниппет для вставки. Установка на uCoz: сниппет в глобальный блок/шаблон через панель или через uCoz MCP (templates_tool).

## 6. Не делаем сегодня (non-goals)

Голос, омниканальность (Telegram/WhatsApp), универсальную RAG-платформу, векторные БД, мультиязычность, оплату, интеграцию с CRM и RuSender (показываем как roadmap), авторизацию в админке сложнее токена.

## 7. Критерии приёмки

1. Сайт индексируется по URL за < 2 минут без ручной подготовки.
2. На 10 тестовых вопросов по контенту сайта ≥ 8 корректных ответов со ссылкой на страницу-источник.
3. На вопрос вне контента сайта агент не выдумывает, а честно говорит, что информации нет, и предлагает оставить контакт.
4. Лид с контактом и резюме появляется в админке в течение 2 секунд после того, как посетитель оставил телефон.
5. Виджет устанавливается на uCoz-сайт одной строкой и работает на десктопе и телефоне.
6. Ответ агента < 5 секунд (p95).

## 8. Сценарий демо (90 секунд)

Открываем uCoz-сайт автосервиса без виджета → в админке вставляем URL → индексация (счётчик страниц) → копируем сниппет → вставляем в uCoz (через MCP или панель) → обновляем сайт, виджет на месте → посетитель: «сколько стоит замена масла на Camry и можно ли в субботу?» → ответ по ценам сайта со ссылкой → «а гарантию даёте?» → ответ → «а можно завтра к 10?» → агент уточняет марку/год, просит телефон → лид с резюме в админке → вопрос-ловушка «делаете ли вы тюнинг выхлопа?» → агент честно: на сайте нет, предлагает уточнить у мастера.

## 9. Связь с деньгами и дистрибуция (для жюри)

Ценность для клиента: конверсия посетителей в контакт растёт за счёт ответа в момент вопроса; лид приходит уже с квалификацией. Монетизация: модуль uCoz «AI-консультант» как надстройка к тарифу (месячная плата за сайт + лимит диалогов) — деньги привязаны к сайту, что укладывается в модель revenue share. Дистрибуция: (1) нативный модуль/skill в каталоге uCoz с установкой через MCP за одну команду; (2) рассылка по действующей базе uCoz «на вашем сайте посетители задают вопросы — вот консультант, включается за 10 минут»; (3) агентства и веб-мастера как канал upsell; (4) публичная демо-страница «вставь URL своего сайта — поговори с ним» как лид-магнит.

## 10. Риски и страховка

Галлюцинации → жёсткий промпт, ответы только из найденных фрагментов с цитированием источников, запрет на цены/сроки, которых нет в тексте; вопрос вне контента → честный отказ + handoff. Медленный или упавший LLM на демо → кэш ответов на демо-вопросы и заранее записанный ролик. Сайт плохо индексируется (JS, странная вёрстка) → ручной «доп. текст» в конфиге сайта (часы, адрес, правила). Установка на uCoz в последний момент → ставим сниппет за час до демо, держим локальную демо-страницу с тем же виджетом.

## 11. Roadmap после хакатона

Lead scoring по истории диалогов, передача лида в RuSender (nurture) и в CRM, запись на услугу с выбором слота, каталог товаров uCoz Shop через shop_tool, мультиязычность, аналитика «какие вопросы задают, чего нет на сайте» как подсказка владельцу, что дописать.
